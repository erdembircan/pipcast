# Open questions

Each question names what would settle it.

1. **How is the picture drawn inside our window?** The window is ours, so the feed does not have to be video. A web view inside the proof of concept's panel could run this system's components as they are, which would make the review boards the renderer. Native AppKit or Core Animation drawing is the alternative. Settle it with a probe: a web view in the panel, checked for frame rate and for never taking the keyboard (technical reference 4.3).
2. **How does live data reach the window?** The proof of concept cannot send the overlay anything once it runs: its standard input closes at once. Its technical reference proposes a file per session that the mod writes and the overlay watches, or a socket on the loopback interface. The file is the smaller step.
3. **Where does return take you?** Bringing the Claude desktop app forward is simple, and the window then hides by itself. Opening the tracked session's own window is not yet possible: nothing in the mod API says which window shows which session.
4. **Which engine events mark each story?** Confirmed in the mod API's types and the current hooks reference (21 October): needs your input is `PermissionRequest` for a permission ask, and the `AskUserQuestion` tool call (`PreToolUse`) for a question; finished is `Stop`, which says nothing of files, so changes come from `PostToolUse` on the edit tools, Bash's edit diff or `git status`, and a `Stop` with background tasks or scheduled wake-ups still pending is still working; stopped on an error is `StopFailure`, with its kind (rate limit, overloaded, server error, a login or billing problem, a reply too long, and others). Not documented, so not relied on: whether a usage-limit pause or a context grown too long ends a turn with any event. None of it has been exercised: settle it with a probe that logs each event in a real session.
5. **One window for every session?** The proof of concept starts one overlay per tracked session. A newsroom wants one window that knows every session.
6. **Sound: on or off?** Decided: BREAKING NEWS and the hour each have an intro and an outro jingle, all on the station's four-note logo, all composed (Sound, in the README). Sound is switched on and off from the window's hover controls; it starts on, the window remembers the choice, and it plays at the Mac's volume.
7. **The channel's name.** Decided: KLWD, US-style call letters that read as "Clawd".
8. **A 3D anchor?** A Clawd modelled and animated in 3D (Blender, say) could replace the pixel anchor. It would arrive as pre-rendered loops per act (idle, talk, urgent, cheer), sized to the anchor slot (324 × 180 stage px at x 138, y 211) and keyed in behind the desk, so nothing else on the stage moves. Settle the look of one act before rendering the rest.
9. **Privacy.** The window is an ordinary window, so it appears in screen shares and recordings, showing session titles and Claude's questions.
10. **What does the hour count?** The report on the hour needs, per session and per hour: lines added and removed, and each change of state with its time. Nothing logs these yet; they would travel with the live data (question 2). Until then the hour's numbers on the boards are examples.
11. **A report the window misses.** Decided: the window hides while Claude is in front (the proof of concept's Visibility.swift), so it can be hidden at the hour. Then that hour's report is skipped, and the next report covers everything since the last one that aired. A report joins the queue only if the window shows as the hour strikes; one that has joined waits through a hidden window until the next report comes due (24 October; until then a report the window missed still aired if the window showed within ten minutes of the hour).
12. **Is 18:00 special?** Decided: no. Every hour gets the same report.
13. **The station clock's face.** Decided (21 October): the dial, in the wall monitor's chrome bezel with a glossy face, gold marks and chrome hands, picked on the KLWD station clock canvas; and no strip or subtitle under ON THE HOUR.
