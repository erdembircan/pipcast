# Mark

The station mark: KLWD in chrome, and nothing else. The bug is this mark at 40px; the Brand page shows it large.

- `size`: the letters' size in px. Everything is set in em, so the mark holds its shape at any size.
- `text`: KLWD by default.

The lettering is italic, 900 weight, expanded 120%, in the chrome gradient with a dark edge and a drop shadow. Nothing is added to it: no swoosh, rule, stripes, badge or chevron. It was chosen over all of those on the Brand page, so the bug, the opens and the hour's open carry no gesture of the mark's own.
