# StatePill

A session's state as one word on a glossy pill in the state's colour: INPUT on red for needs your input, ERROR on red for stopped on an error, READY on green for finished, LIVE on gold for working.

- Provide `state`: `needs-input`, `error`, `ready` or `working`. `label` replaces the word.
- Anybody italic 900 at 28px, expanded 130%, on `radius-tag` corners.

The word is the signal; the colour backs it up. The listing and THE HOUR IN REVIEW use it.
