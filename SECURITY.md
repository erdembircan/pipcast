# Security

Pipcast runs on your Mac, as a mod inside each Claude Code session and as a small macOS app that comes with it. If you find a security problem in it, report it privately, not in a public issue.

## Report a problem

On Pipcast's GitHub repository, open the **Security** tab and select **Report a vulnerability**. The report stays private between you and Pipcast's maintainer. Say what you found, how to make it happen, and which versions of Pipcast, macOS and Claude Code you have.

You'll get an answer there. Once the problem is confirmed, the fix ships in a new version of Pipcast.

## Supported versions

Only the newest version of Pipcast gets fixes.
